# Chrome Extension (apps/chrome-extension)

## Purpose
Enables autonomous and assistive browser workflows by communicating with the Unified AI Assistant backend and local Chrome instance.

## Planned Scope (Future Phases)
- Manifest V3 extension structure.
- Content script and service worker communication.
- Secure token-based WebSocket connection to the local API / agent worker.
- DOM snapshot capture, tab coordination, and interactive execution overlay.

## Status in Phase 0
- Scaffolding initialized.
- No third-party agent dependencies or frameworks installed.
