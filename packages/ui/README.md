# UI Component Library (packages/ui)

## Purpose
Shared UI design system components styled according to the Claude-inspired dark theme specification.

## Planned Scope (Future Phases)
- Dark-theme primitives (tokens, colors, typography: serif AI response styles).
- Navigation sidebar components (New Chat, Search, Projects, Browser Agent, Calendar & Tasks, Files & Knowledge, Wi-Fi Sensing, Settings).
- Message cards, code blocks, and streaming response displays.

## Status in Phase 0
- Scaffolding initialized.
