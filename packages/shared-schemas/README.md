# Shared Schemas (packages/shared-schemas)

## Purpose
Monorepo shared data contracts, TypeScript types, and JSON Schema definitions shared between `apps/web`, `apps/chrome-extension`, and `services/api`.

## Planned Contracts (Future Phases)
- Chat session, message, and citation schemas.
- Browser action and observation schemas.
- Task, calendar event, and reminder models.
- Wi-Fi sensing presence event definitions.

## Status in Phase 0
- Scaffolding initialized.
